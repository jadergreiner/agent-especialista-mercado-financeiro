🤖 Agent Especialista Mercado Financeiro

Plataforma de IA avançada para análise de mercado, trading automatizado e gestão de risco profissional

🎯 Visão Geral

O Agent Especialista Mercado Financeiro é uma plataforma completa de IA que combina análise técnica, fundamentalista e de sentimento para fornecer insights precisos sobre o mercado financeiro. Desenvolvido especificamente para traders e analistas que buscam vantagem competitiva através de tecnologia avançada.

✅ Status Atual: 11/11 componentes implementados - Sistema totalmente operacional com integração completa às corretoras

🚀 Funcionalidades Principais

📊 Sistema de Alertas Avançado

Notificações multi-canal (console, webhook, Telegram, arquivo) com filtros inteligentes, rate limiting e histórico persistente em SQLite para oportunidades de mercado em tempo real.

🌐 Dashboard Web Interativo

Interface web responsiva com Flask + Plotly exibindo contexto macroeconômico (VIX, Treasury, S&P500, DXY, ouro, petróleo), oportunidades de trading, portfólio e alertas com atualização automática.

💾 Otimização de Persistência

Sistema avançado de armazenamento com versionamento, compressão automática, arquivamento inteligente e APIs RESTful para máxima performance e eficiência de espaço.

📈 Backtesting Avançado

Framework completo de backtesting multi-timeframe com métricas de risco (Sharpe, Sortino, drawdown), simulação de slippage/custos e relatórios detalhados de performance.

🏦 Integração com Corretoras

Conectividade completa com Alpaca, Interactive Brokers e modo simulado. Execução automática de ordens, sincronização de portfólio e trading live/paper com APIs nativas.

🤖 Trading Automatizado

Estratégias configuráveis (média móvel, RSI, breakout) com gestão automática de risco, position sizing dinâmico e execução otimizada baseada em sinais de mercado.

📊 Monitor de Portfólio

Análise em tempo real de P&L, Sharpe ratio, drawdown, volatilidade e diversificação. Sistema inteligente de alertas para concentração excessiva e limites de risco.

🔗 Análise de Correlação

Monitoramento avançado de relacionamentos entre ativos globais (ações, forex, commodities, crypto) com janelas rolantes de correlação e detecção de regimes de mercado.

🎯 Sistema de Níveis de Preços

Análise ML-powered de níveis críticos de suporte/resistência com validação histórica, machine learning para predição e integração com estratégias de entrada/saída.

📰 Análise de Sentimento

Processamento de sentimento de múltiplas fontes (notícias, redes sociais, dados de mercado) com pontuação quantitativa e impacto na tomada de decisão de trading.

📊 Análise Macro

Monitoramento contínuo de indicadores macroeconômicos, eventos de bancos centrais, dados econômicos e impacto em diferentes classes de ativos.

🔍 Validação Histórica

Sistema robusto de validação de estratégias contra dados históricos com métricas de assertividade, análise de overfitting e relatórios de performance detalhados.

🛠️ Tecnologias Utilizadas

  • Backend: Python 3.10+ com asyncio para processamento assíncrono
  • Dados: pandas, numpy, yfinance, TA-Lib/pandas-ta
  • Web: Flask + Plotly para dashboards interativos
  • Persistência: SQLite com otimização avançada
  • APIs: alpaca-trade-api, ib-insync para corretoras
  • ML: scikit-learn para análise preditiva

🚀 Como Utilizar

1. Instalação Rápida

# Criar ambiente virtual python -m venv .venv .\.venv\Scripts\Activate # Instalar dependências pip install -r requirements.txt # Dependências opcionais para corretoras pip install alpaca-trade-api ib-insync

2. Configuração

# Executar instalador automático python backend/instalar_integracao_corretoras.py # Editar configurações notepad config/corretoras.json notepad config/estrategias.json

3. Execução

# Demonstração completa python backend/sistema_integrado_trading.py --demo # Sistema em produção python backend/sistema_integrado_trading.py

4. Dashboard Web

Acesse http://localhost:5001 para visualizar o dashboard interativo com métricas em tempo real.

🛡️ Gestão de Risco

🎛️ Controles de Posição

Position sizing automático baseado em risco por operação (2%), stop loss (5%) e take profit (10%) configuráveis.

📉 Limites de Drawdown

Proteção contra perdas excessivas com limites de drawdown máximo (15%) e perda diária (3%).

⏰ Controles Temporais

Execução apenas em horários de mercado válidos com kill switch emergencial.

📊 Diversificação

Monitoramento de concentração por ativo (máx. 20%) e análise de correlação de portfólio.

📈 Estratégias de Trading

📊 Média Móvel

Crossover de médias rápidas/lentas com filtros de tendência e volume para entradas precisas.

📈 RSI Oversold

Detecção de condições de sobrevenda com níveis configuráveis (30/70) e filtros de momentum.

🎯 Breakout

Identificação de quebras de resistência/suporte com validação de volume e volatilidade.

🔄 Mean Reversion

Estratégias contrárias baseadas em desvios da média com análise de reversão estatística.
