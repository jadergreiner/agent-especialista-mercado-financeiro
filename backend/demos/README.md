# Scripts de Exemplo e Demonstração

Esta pasta contém scripts de exemplo e demonstração para facilitar o entendimento e uso dos principais módulos do projeto.

## Convenções
- Scripts de exemplo/demonstração devem ser movidos para esta pasta.
- Scripts de produção permanecem no diretório principal ou em submódulos específicos.
- Scripts de teste devem estar identificados como `test_*.py` e ficar na raiz do backend ou em uma pasta de testes.

## Exemplos típicos
- Integração de boletins
- Demonstração de motores de oportunidades
- Exemplos de uso de APIs

> Mantenha este README atualizado ao adicionar novos exemplos.
