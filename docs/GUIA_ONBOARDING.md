# Guia Rápido de Onboarding

## Objetivo

Facilitar a integração de novos membros ao projeto Agent Especialista Mercado Financeiro.

## Passos Iniciais

1. Leia o `docs/README.md` para visão geral e links úteis.
2. Configure o ambiente Python conforme `requirements.txt`.
3. Consulte o `docs/TEMPLATE_DOCUMENTACAO_MODULO.md` para padronização de novos módulos/scripts.
4. Veja o `docs/GUIA_TESTES_AUTOMATIZADOS.md` para práticas de testes.
5. Registre dúvidas e pendências no backlog: `docs/gestao-agil/backlog.md`.

## Estrutura do Projeto

- `backend/`: Lógica principal, agentes, análise, dados, estratégias, risco, utilitários.
- `docs/`: Documentação centralizada.
- `scripts/`: Scripts utilitários e automação.
- `web/`: Interface web e dashboards.

## Canais de Comunicação

- [ ] Definir canal oficial (ex: Slack, Teams, e-mail)
- [ ] Nome do responsável pelo onboarding: <nome>

## Governança e Fluxos

- Todas as pendências devem ser registradas no backlog.
- Siga as convenções de nomenclatura e arquitetura do projeto.
- Consulte o Product Owner para dúvidas de priorização.

## Checklist de Onboarding

- [ ] Ambiente Python configurado
- [ ] Documentação lida
- [ ] Primeiro commit realizado
- [ ] Dúvidas registradas no backlog
